## Literature fact versus project judgment

SUMO documents separate RNG uses and Krauß `sigma` speed perturbation; the 2×2 altered-model sensitivity and exact early nonlocal control are project-specific diagnostic judgments, not published causal identification thresholds ([SUMO randomness](https://sumo.dlr.de/docs/Simulation/Randomness.html), [vehicle types](https://sumo.dlr.de/docs/Definition_of_Vehicles,_Vehicle_Types,_and_Routes.html)). Sargent's simulation validation framework separates code verification from operational validity and supplies no portable 30-s or speed-difference acceptance value ([Sargent 2013](https://doi.org/10.1057/jos.2012.20)). FHWA guidance supports considering freeway benefit jointly with ramp queue and adjacent-road costs, but does not certify this synthetic program or geometry ([FHWA Ramp Management Handbook](https://ops.fhwa.dot.gov/publications/ramp_mgmt_handbook/manual/manual/10_1.htm)). The chosen 22G is inherited from the previously tested arm because it produced a real R admission contrast; it is **not** chosen for a favorable M result.
