# Sequential decision tree — proposed, no execution release

All decisions use the prewritten witness/background rules, not a score or favorable visual impression. Every new condition needs a separately reviewed exact card and explicit start authorization. No branch silently repeats a failed scientific result. A global technical, mapping, parser, source or attribution defect stops the scan; fix/review belongs to a new task.

**Branch order is conditional, not the CSV row order.** A confirmed self-congested 3350.4 R0 jumps directly to the lower 3199.2 R0 pair and skips 3499.2. An unresolved 3350.4 R0 may try 3499.2 first only if an independent, signed, hash-bound audit documents why the issue is confined to that realization and rules out a common network/source/lane-map/parser/downstream measurement defect; only if 3499.2 R0 is then adjudicated self-congested may the lower 3199.2 pair be attempted. A global defect **or unknown issue scope** stops pending audit. These branches are mutually exclusive for the Stage A four-start cap.

1. **Offline gate, zero starts.** Review the existing 3350.4/R0 raw and all v3/suitability receipts. Preserve fixed screen FAIL/F5/C. Assign only the new proposed background-evidence status: `LOW_R_BACKGROUND_ACCEPTABLE`, `TOO_HIGH`, or `NOT_EVALUABLE`. This is retrospective selection of an already observed control; fix the revised criteria before any future delayed-R treatment outcome and disclose the selection bias. Acceptable requires affirmative bounded absence of sustained self-congestion and cleared relevant alternatives, not merely P/S/L negative. If this new contract has not received independent scientific approval, no run can be released.
2. **If 3350.4 acceptable:** propose one seed17 qMain3350.4 delayed-R720 A_OPEN start. If it produces a valid witness, **STOP demand scan**. If adequate R exposure but no qualifying sustained M event, mark that pair `TOO_LOW` for this tested ramp profile and proceed to step 4. If a relevant artifact or event-order ambiguity prevents inference, mark `NOT_EVALUABLE`; global defects STOP, point-specific defects permit only the predeclared step 4.
3. **If 3350.4 truly self-congested:** mark `TOO_HIGH`; propose 3199.2/R0 first and delayed-R720 only if R0 is acceptable. If witness, STOP; otherwise STOP Stage A, with no arbitrary lower candidate. If 3350.4 is still `NOT_EVALUABLE`, proceed to step 4 only after the independently signed, hash-bound point-specificity audit described above; otherwise STOP pending audit without calling it low or high.
4. **Higher test:** propose 3499.2/R0. If R0 is already sustained self-congested, mark `TOO_HIGH`. If a valid 3350.4 delayed-R720 negative gives a bracket, go to Stage B; otherwise, if 3350.4 was unusable, the sole remaining lower fallback is step 3's 3199.2 pair. If 3499.2/R0 is acceptable, propose its delayed-R720 arm. Witness ⇒ STOP. Valid no event ⇒ `TOO_LOW` for that tested pair and STOP; artifact/ambiguous event ⇒ `NOT_EVALUABLE` and STOP. Do not call missing R insertion “TOO_LOW.”
5. **Stage B, only for one clean bracket:** qMain3350.4 valid R0 plus valid delayed-R720 negative, and qMain3499.2 R0 confirmed self-congested. Propose qMain3420.0 (M1425) R0, then delayed-R720 only if R0 acceptable. Witness ⇒ STOP demand scan. Any other outcome ⇒ `NO_WITNESS_WITHIN_BOUNDED_SCAN` if all attempted comparisons are evaluable negatives/high controls, otherwise `NOT_EVALUABLE_WITHIN_BOUNDED_SCAN`. No second intermediate value or ramp-rate change.
6. **After witness:** record the exact witness count/profile/seed and cease demand selection. Preparation of a fixed A/B/C design may begin, with A equal to the witness's A_OPEN delayed-R arm. A separately approved matched seed23 pair may check minimal robustness; satisfactory confirmation is required before strong Stage 6 closeout or B/C **execution**. No B/C run is authorized by this tree.

Classification is candidate-local, not a monotonic traffic-law assertion. `TOO_LOW` requires a valid low-R comparison and valid high-R exposure with no qualifying event; it is not inferred from nominal 720 alone. `TOO_HIGH` requires an independently adjudicated sustained low-R event with source/downstream/geometry exclusions, not a failed 0.85 screen. `PROMISING_WINDOW` is assigned only to a valid witness pair. Warning-only or other near-miss observations are retained descriptively but do not release a candidate or alter progression; Stage B uses only its exact predeclared bracket. `NOT_EVALUABLE` retains the exact missing evidence and consumes any attempted scientific condition.
