# Bounded run budget and stop rules — planning envelope only

No starts are authorized by this document. A future run requires an exact, separately reviewed card, exclusive output path, explicit user authorization, and an independent post-run engineering → data → scientific gate. No executable card is generated in this planning task.

| Portion | Maximum **new** SUMO starts | Conditions |
|---|---:|---|
| Stage A coarse search | 4 | Existing 3350 R0 uses zero; at most one new delayed3350 arm plus two-run higher or lower pair, or two new pairs if 3350 is point-specific unresolved |
| Stage B one intermediate qMain pair | 2 | Only the exact valid 3350-negative/3499-R0-high bracket; one R0 and one delayed R720 at3420. This branch has used only two Stage A starts. |
| Optional seed23 robustness | 2 | Only after seed17 witness; matched R0 + delayed R720, never treatment alone. Skipping it prevents strong Stage 6 closeout. |
| Separate A/B/C follow-up | 2 | Reuse seed17 A_OPEN witness A; one prospectively fixed B and one C. Planning may begin after the witness; execution requires satisfactory matched seed23 evidence and fresh scientific design review. |
| **Feasible total Stage 6 final ceiling** | **8** | Branch-aware maximum: four demand-scan starts across A+B, then at most two matched confirmation and two B/C starts. A's four-start branch and B's two-start branch cannot both occur. |

Although the separate per-stage envelopes are A≤4 and B≤2, **the combined demand scan is capped at four new starts**. Stage B is triggered only after a valid 3350 delayed high-R negative (one new start) and a self-congested 3499 R0 (one new start), leaving at most two starts for the 3420 pair. The alternative four-start Stage A route cannot trigger Stage B. These branch constraints are part of the budget, not discretionary spare starts.

Minimum incremental starts for a witness: **one** if the already-observed 3350.4 R0 run is retrospectively adjudicated as a usable low-R background under criteria fixed before the future delayed-R treatment outcome, and its new delayed-R720 mate succeeds. Given the present unresolved C/F5 state, the minimum without that successful offline adjudication is **two** for a new matched R0/delayed-R720 pair. Historical t0 R720 runs are not delayed-treatment substitutes. The minimum for *full Stage 6 closeout* is larger because matched confirmation and A/B/C evidence may be needed; no fixed count is promised before outcomes.

Stop demand scanning immediately on a valid witness. Stop an individual pair before its high-R arm if its R0 arm is adjudicated self-congested, source-starved or non-evaluable. Stop the whole scan on a global mapping, parser, network, source, geometry or measurement defect. A scientific negative consumes that candidate; it never licenses an automatic stochastic rerun. A technical failure before simulation start consumes no SUMO start, but any repeat must have a separately approved retry rule; a started run, even incomplete, consumes one start and is preserved. No automatic technical retry is budgeted. There is no “spare” start for attractive results or for improving a plot. Seed23 is not run at every candidate. After the single optional matched confirmation pair, no third seed is released.

If all permitted, interpretable pairs are negative or self-congested and the one allowed refinement (if triggered) is negative, report `NO_WITNESS_WITHIN_BOUNDED_SCAN`. If a material technical/measurement/attribution gap prevents decisive comparison, report `NOT_EVALUABLE_WITHIN_BOUNDED_SCAN` and the exact gap; do not substitute a negative result. If seed23 is skipped, strong Stage 6 closeout and B/C execution remain unreleased. If seed23 fails to reproduce the seed17 witness, retain the single-seed witness as observed but mark Stage 6 reproducibility unresolved and stop rather than selecting a new seed. All endpoints preserve O2 NOT_RESOLVED until the full mechanism/trade-off chain is independently reviewed.
