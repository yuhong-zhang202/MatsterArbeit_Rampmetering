## 4. 这是实质风险边界变化

现合同会在不满足项目见证时阻止首黄灯运动；拟议合同允许在记录该不满足后观察原生处理。这是从额外前置阻止转向有界原生运行与事后观测，**不能保证一个仿真步内绝不出现异常**。监测可阻止后续运动，不能撤销已发生的仿真事件。身份、相位、覆盖、制动、碰撞、红灯、车尾、接收空间和日志检查继续存在，并不意味着安全责任完全相同。

因此此前仅批准1.1m分类的授权不覆盖这项变化。项目AGENTS.md第2节要求不能自行改变此类控制／停止合同；需用户明确批准后才可实施和运行。若不接受，应保留当前STOP和适用边界，停止本路线的重复诊断。
