## Decision in plain terms

The A07 run stopped because its *custom* red-transition check demanded 1.1459706723353782 m from a car 1.001999189766508 m before the lane end. The next red motion step was never executed. SUMO's native stopping logic uses a different, discrete calculation and a desired stop offset around 1 m in this bound setup. This makes the inherited custom rule worth reviewing; it neither proves that the red transition would have been safe nor supplies a replacement threshold. **Proposed:** first derive A1, an explicit division of responsibility between SUMO's vehicle response and an actor-specific transition eligibility check. Keep the current HOLD until that check, input coverage and offline counterexamples are independently reviewed. If A1 cannot be derived, evaluate A2's independently justified discrete guard; do not guess new numbers.

## 1. STOP3: observed guard mechanism

**Observed.** At `t=1206 s`, `CA_C24` was at phase `y`, with `nextSwitch=1206.0`. The worker checked the *prospective* `r` state before 1206→1207 `simulationStep`; it refused and did not execute that step. The controlled link was `ramp_storage_0 → ramp_accel_0` through `:ramp_mid_0_0`; storage lane length was 204.49 m. The guard covered 27 storage and 15 ingress R vehicles; only storage vehicle `R_flow.1` failed. Its front was at 203.4880008102335 m, yielding `g=1.001999189766508 m`; speed `v=0.04573822948686786 m/s`, normal deceleration `b=4.5 m/s²`, and the configured step/action interval was 1 s. Receiver availability was recorded, but its numeric secure-gap value was not independently recomputed. [Original bound runtime review](../../artifacts/candidate_a_qualification_20261008_v1/engineering/R300_A07_RUNTIME_ENGINEERING_REPORT.md), [new engineering readback](../../artifacts/candidate_a_safety_contract_20261011_v1/engineering/ENGINEERING_REVIEW.md).

**Observed/local arithmetic.** Existing [Candidate A guard](../../src/candidate_a_qualification_20261008/safety.py) checks every positive-speed relevant vehicle against `g_required = 1.1 + v·1 + v²/(2·4.5)` metres. The terms here are 1.1 m inherited clearance, 0.04573822948686786 m full-speed response allowance, and 0.00023244284851037648 m continuous braking term; total 1.1459706723353782 m, margin `g−g_required = −0.14397148256887027 m`. Merely replacing 1.1 by 1.0 in this **offline algebra** still demands 1.0459706723353782 m, above the observed gap. That is not a proposed source edit or counterfactual SUMO result. The 1.1 m provenance is a prior local guard, without verified physical or SUMO minimum status. [Tagged native diagnosis](../../artifacts/candidate_a_qualification_20261008_v1/engineering/R300_A07_GUARD_NATIVE_DIAGNOSIS.md).

**Limit.** The refused red step, subsequent follower/receiver response and complete cycle have no observation. No collision/emergency in the executed prefix is not a red-transition safety certificate. The current-contract STOP3 is valid because the reviewed guard cannot advance this transition and a contract-preserving repair was not found; it is not proof that native SUMO red is unsafe, Candidate A is generally impossible, or 900 veh/h is physically impossible.

## 3. Safety-obligation matrix

| Domain | What native SUMO can cover | Additional actor obligation / boundary | Unknown-state rule |
|---|---|---|---|
| Approaching front | Signal-aware stopping and Krauss speed choice, including inability-to-brake handling. | Bind actual controlled link, stopline, phase event, type/modes; determine eligible red-transition state without relying on unvalidated continuous formula. | Deny transition if state, model or eligibility is unknown. |
| Followers | Car-following response to a visible leader. | Enumerate affected storage followers and test/review approach behaviour, emergency braking and rear-end observations at transitions. | Unlisted vehicle or missing dynamics closes the gate. |
| Ingress and unseen entrants | Native dynamics/insertion during a step. | Bind upstream route, internal connector, type, speed and one-step reachability so pre-step enumeration cannot miss a vehicle reaching the link. | Unknown route or reachability closes the gate. |
| Controlled link and signal | Native program applies state per link; TraCI can request phase/program changes. | Bind exact link and G/y/r sequence, requested and actual phase, timing and next switch; reject stale or unexpected transitions. | Mismatch closes the gate. |
| Yellow-to-red | Native braking decision under observed model. | Separately assess approach commitment, yellow sufficiency and conflict clearance. Existing 3 s yellow is a local choice, not a cited universal safe duration. | No validated eligibility, no red step. |
| Receiver, leader, downstream conflict | Native following/junction logic. | Preserve route-aware receiver/leader checks and actual crossing/conflict monitoring. A07 receiver secure-gap numeric value remains unrecomputed. | Missing receiver/foe state denies release. |
| Other classes | Generic native model still applies. | Show that no unlisted R/U/X/M or changed type can use controlled link or affected approach. | Unknown population closes the gate. |

This matrix is a set of **proof obligations**. It does not claim all obligations were met in the refused A07 state. Native collision avoidance and repeated actor qualification are different claims.
