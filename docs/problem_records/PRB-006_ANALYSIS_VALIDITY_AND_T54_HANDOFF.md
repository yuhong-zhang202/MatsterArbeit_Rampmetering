# PRB-006 — 早期分析器假通过与T54交接证据资格

- 日期／阶段：2026-09-13，Stage3–5独立复审。
- 影响：高；输入坏掉仍可能输出通过，且结论到证据的索引不完整。
- 状态：限定该批分析防错／证据映射技术缺陷CLOSED；T54历史用户接受不自行补全。

## 发现和根因

Astra复审发现四类不合格输入可能仍被旧分析器判通过：FCD缺速度、未知lane、TLS时间改动、E1有贡献却无有效速度。此外12个证据编号没有完整原文件映射，5个不可跨seed配对键被跳过。程序exit0不足以证明测量有效；缺少的配对不能当零差值。[独立复审原报告](../探索验证阶段/STAGE3_STAGE5_ASTRA_REVIEW_20260913.md)。

## 采取的方案及效果

修复必要输入/合同验证后33/33离线测试通过，15种异常变异被拒；8档案96/96既有产品保持不变。12个证据编号补齐23条精确路径/哈希，5个缺配对键显式披露。修复的是分析资格与可追溯性，没有为了通过而改旧观测或排除阴性运行。[修订T54包](../探索验证阶段/EXPLORATORY_VALIDATION_T54_ACCEPTANCE_PACKAGE_REVISION_02.md)、[工程复审](../../data/processed/astra_stage3_stage5_engineering_reaudit_20260913_v1/ENGINEERING_REAUDIT_REPORT.md)。

## 结果边界与后续防范

这些回归只覆盖登记缺陷，不保证所有未来输入都被识别。修订包自身仍写待用户接受，不能把科学建议、工程完成或后来的Stage6结项倒写为T54已获用户批准。旧Q2/Q4阴性按原系列保留，见[PRB-005](PRB-005_EARLY_SCENARIO_READINESS_AND_OBSERVATION_DOMAIN.md)。

后续应分开：原始值缺失／观测零／部分观测；身份和断面计数／贡献量；技术检查通过／研究门成立。该原则也适用于后来的服务窗口null修复和终点phase审计，但这些不是同一个版本的缺陷，见[PRB-004](PRB-004_NOMINAL_TWO_CAR_DISCHARGE.md)。本文不重新测试或更改T54状态。
