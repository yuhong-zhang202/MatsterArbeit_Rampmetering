## 4. 机制与适用边界

1. R900实际评价窗R汇入为900/904/898veh/h；R/U无源头插入等待。S17/S42的主线等待出现在队列到达入口之后，最大58/65s；S23严重状态没有延伸到入口，M插入等待为0。不是以源头先堵制造的Merge假象。
2. S17/R900：core14/15约750s出现持续低速，之后向上游传播；源头附近明显低速约2350s，首个>1s插入延迟计划2456、实际2458s。S23/S42独立原始复算同样支持从Merge附近向上游发展，下游仍可接收。严格正常起点参照仍有ONSET_UNRESOLVED，不能把空间机制佐证改写成该数值起点门槛已通过。
3. R1200两组实际R评价流率约1044veh/h，城市R/U最大插入等待274/275s。M3000/R1200主线没有P/S持续状态，M3600/R1200则严重拥堵；请求R1200不能当作真实汇入1200。M3600/R1200两辆R在输出精度下于294.51m辅助车道终点完成换道，不能沿用旧实验“全在终点前”的表述。
4. M4200/R0的P150s先出现于上游，向下游行进，支持移动慢车团/跟驰压缩解释；不是自动识别出的固定Merge容量瓶颈。
5. 严格FREE_FLOW_CANDIDATE门槛对轻扰动敏感，低需求点也可能落入TRANSITION_OR_DISTURBED。此残余类不意味着已近容量。相对畅通与持续回堵要结合空间图、积累、流量和车辆成本解释。
