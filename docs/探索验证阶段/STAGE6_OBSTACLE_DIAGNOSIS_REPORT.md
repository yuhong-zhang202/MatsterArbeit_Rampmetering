## 4. 为什么只选择 H2

H2 是当前唯一被全部 12 条运行直接、定量支持的观测域问题，而且可以先使用已经存在的上游道路，避免同时改变路权、驾驶行为、信号、匝道储存和需求。它直接关系到 Q2：若车辆没有真实经过所声称的上游路段，就无法用该路段的状态描述合流前主线受损，也无法可靠判断 Q2 与 Q3 是否属于同一场景状态。

这不是对“道路加长”的批准。B 应优先论证在现有 1,394.87 m `main_up` 内限制主线实际入口，使车辆经过登记的 feeder 和公共观测域。只有工程证据证明现有几何无法实现时，才可提出几何变化，并将其作为新组合干预重新审核。

入口改变会同时影响旅行时间、到达合流的序列、车道使用与实际输入。因此验证首先判断候选场景是否具有研究用途，不把结果解释为入口距离的纯因果效应。

## 5. B 段必须预先区分的结果

1. **技术预测成立：**实际入口、经过距离、连续观测和车辆/需求端点全部达到登记要求。这只证明入口域修正成功。
2. **科学预测得到支持：**在合格的同版本 reference 下，challenge 满足预登记的 M 主判据与佐证，并保留有解释力的 R 通行、积存和 U 暴露证据。此后仍须通过 SG6-R 的其他门。
3. **有效阴性：**数据、配置和输出合格，但入口域改善后 Q2/Q4 仍不满足，或候选入口本身造成注入不足/新入口瓶颈，记为 `not_resolved`；不得用技术重试改善科学结果。
4. **证据错误：**来源、身份、时间网格、关键观测或解析错误使结果无法解释，且无法在已批准技术修复范围内纠正，记为 `blocked_by_evidence_error`。
