# 论文研究控制台使用说明

这个控制台是本地工具，不依赖公开网站。论文结构、Todo、参考文献、导师意见、实验状态与研究决策统一保存在：

`data/thesis-dashboard.json`

## 启动

```bash
npm install
npm run dev
```

在终端显示的本地地址打开控制台。建议使用最新版 Chrome 或 Edge。

## 首次连接数据

1. 点击页面顶部的“连接数据文件”。
2. 选择 `data/thesis-dashboard.json`。
3. 授权后，网页中的修改会自动写回这个文件。

浏览器只记住文件句柄，所有论文状态仍以 JSON 文件为唯一事实来源。可以随时使用“立即保存”和“从文件重载”。

## 与 Codex / GPT 协作

让 AI 每次开始论文任务前先读取：

1. `data/thesis-dashboard.json`
2. 与当前任务相关的代码、数据或论文文件

完成工作后，要求它仅根据真实完成情况更新 JSON：

- 修改少量顶层事项的状态；
- 更新 `meta.currentPhase`、`meta.nextMilestone` 与 `meta.updatedAt`；
- 新增导师意见、文献、实验或研究决策；
- 不得把“计划执行”误标为“已完成”；
- 不得删除尚未解决的导师意见或研究决策。

可直接使用下面的提示词：

> 先读取 `data/thesis-dashboard.json` 了解论文当前状态。完成本次任务后，根据实际结果更新对应 Todo、当前阶段、下一里程碑、实验状态和必要的决策记录。不要根据计划推测完成状态，也不要改动与本次任务无关的条目。

如果 AI 修改了 JSON，在已经打开的网页中点击“从文件重载”即可看到更新。

## 阶段与任务展示

- 总览优先显示当前阶段，不展示由 Todo 推算的精确完成率。
- 初步章节不自动生成 Todo，也不参与任务完成率计算。
- 任务列表只保留可执行的顶层事项和明确的等待项；必要步骤作为顶层事项的子步骤展示。
- 任务页使用“待开始 / 进行中 / 已完成”三列看板；每列首次按高、中、低优先级排列，拖动卡片可调整列内顺序或更新状态，卡片底部的左右按钮可用于快速换列。
- 任务管理器的总数只统计“待开始”和“进行中”的任务；“已完成”列保留历史记录，但不计入总任务数。
- 点击任务卡片右上角的三点菜单可以编辑或删除卡片。编辑支持标题、章节、类型、优先级、状态和子步骤；删除前会二次确认，删除文献任务时会同时删除其关联参考文献。
- 添加“文献”类型的任务时会自动创建并关联参考文献；从“参考文献”页添加条目时也会自动创建一个中优先级的文献任务。
- 文献任务与参考文献使用固定 ID 双向同步状态：“待开始 ↔ 待读”“进行中 ↔ 阅读中”“已完成 ↔ 已完成”。参考文献的“使用中”在任务看板中归入“进行中”。
- 尚未确认的研究问题、方法参数和研究范围集中显示在“等待确认”区域。
